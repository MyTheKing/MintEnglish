

# MintEnglish

🔗 **在线体验**: http://testdemo.joshu.xin/#/

#### 产品面向用户群体是

学生、考研、职场、初学者、专家

- 核心场景
  - 背单词
  - 场景学习英语
    - 阅读英文内容、对话练习、听力练习
      - AI来帮助学习英语期间来模拟环境，可以更快的在现实生活中应用英语

#### 产品形态

- 自定义英语智能体
  - 可以全局语音电话沟通，辅助学习英语（类似桌面应用豆包电话沟通）
- 词汇学习
- 图谱
  - 词根词缀（neg- = deny, -otiate = 处理）
  - 同义词（discuss, bargain, mediate）
  -  反义词（accept, agree）
  - 常见搭配（negotiate a deal/contract/price）
  - 点击任意节点可展开新图谱，为词汇图谱，就是一些相近的词汇
- 阅读伴侣
- 自定义生成阅读的文章进行阅听
- 以根据所学习的单词生成文章  
- 记忆系统
  - 可以收集当天学习的词汇，定时第二天发邮件给用户复习（最初遗忘速度最快，复习加深印象）







#### 产品判断

解决一个人在学单词和阅读文章提供帮助。

​	学语言就要去说话聊天，而该产品，提供这种场景模拟英语对话交流

​	在去阅读时，总去阅读一些杂志，有时看起来很无聊。可以自己定义内容，来去学自己想学的文章

#### 设计美感

学习本就枯燥乏味，弄点自然的气息，再加上干净点的页面，心理减少点压力感

#### 交互体验

交互是往流式动画靠，交互过程转场自然点，不能太生硬，在一些按钮，做成实体感，有种触摸的感觉

#### 亮点

目前只感觉是有一个对话场景练习英语吧，可以定义不同场景风格对话

#### 产品深入
- 可以做成桌面应用程序

- 在打电话时，只是对话，AI少了个眼睛，目前只能听与说，不能看。
  - 应该可以读取当前屏幕内容，进行好方便沟通那个地方不会、不了解等问题。
  - 比如阅读文章，我不知道怎么读了，听也不听不懂，我直接打电话让AI一句一句的教我读（因我目前就是这样使用豆包的，给他图片、读取屏幕或者手机相机拍摄）
